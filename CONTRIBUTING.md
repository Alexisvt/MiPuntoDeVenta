# Contributing

## Repository language

Use English for every technical and collaboration artifact:

- source code, identifiers, and code comments;
- commit messages and branch names;
- pull requests, issues, and review comments;
- README files, specifications, ADRs, and operational documentation;
- test names, fixtures, logs, and developer-facing error messages.

Use Spanish only for end-user-facing interface labels and localized product copy intended for the initial Costa Rican audience. Tests may assert that Spanish copy, but their descriptions and implementation remain in English.

Keep the product name `MiPuntoDeVenta` unchanged.

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/) and do not add automated authorship or AI attribution.
